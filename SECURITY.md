# Security policy

## Supported versions

Security fixes are applied to the latest published version of `rn-android-kit`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is available for the
repository. Do not include credentials, keystores, signing passwords, access tokens, or private
application source code in a public issue.

If private reporting is not available, open a minimal issue asking the maintainer for a private
contact method without disclosing vulnerability details.

## Scope

`rn-android-kit` runs local Gradle, ADB, npm, and scrcpy commands. It does not collect telemetry,
upload project data, or read keystore passwords.
